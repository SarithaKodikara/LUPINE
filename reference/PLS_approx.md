# PLS low dimensional approximaton for longitudinal data

PLS low dimensional approximaton for longitudinal data

## Usage

``` r
PLS_approx(X_array, day, ncomp = 1, taxa_names = NULL)
```

## Arguments

- X_array:

  The data array

- day:

  The day to approximate

- ncomp:

  The number of components to use for PLS

- taxa_names:

  The taxa names to use for PLS

## Value

The low dimensional data matrix using PLS
